Real input file benchmark fixtures for existing-condition import tests.

These fixtures are intentionally tiny and deterministic. They are not survey
certification, control, standards approval, or construction readiness evidence.
Civora never stamps, seals, signs, certifies, approves construction, submits
construction documents, or acts as engineer of record.

Fixtures:
- `survey_points.csv`: point/elevation import fixture.
- `constraints.geojson`: parcel, easement, ROW, floodplain, wetland, and existing utility context fixture.
- `surface_pipe.landxml`: LandXML surface and pipe-network metadata fixture.
- `surface_grid.tif`: tiny GeoTIFF/DEM surface fixture.
- `surface_points.las`: tiny LAS/LiDAR point-cloud fixture.
