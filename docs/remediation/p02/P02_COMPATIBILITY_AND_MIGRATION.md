```sh

PYTHONDONTWRITEBYTECODE=1 /tmp/civora-connected-runtime.L1svVb/runtime/bin/python -I -B tests/remediation/run_p02.py --run-id NEW_UNIQUE_RUN_ID
```

The second command creates new local P02 evidence only, verifies anchored P01 bundles and input hashes, and returns1 while P01 product assertions fail. No skip/xfail or `|| true`. The runtime path is local; if absent, choose a separately approved existing Python3.11+ interpreter, not an automatic installation. New output location: `docs/remediation/p02/evidence/<run-id>/`. All older reports stay untouched.

## Migration and rollback controls

No migration is implemented here. Before a future change, inventory representative legacy variants (program-only; foundation v1; canvas v1; inline and sidecar results; edit/calculation/review/export history; unknown units; imported raster/TIN; ambiguous/missing registration). Use synthetic fixtures initially; any real project needs explicit rights/privacy and isolated-copy authorization.

Dry-run checks require unchanged original bytes, IDs, geometry coordinates/order, units/datum uncertainty, source hashes/flags, history references and old result meaning. Reprojection or recalculation produces new derived identity, not a rewritten original. Unknown future schemas fail closed; extension fields survive. Separate input and result revisions; explicit approval before persistent metadata/schema or numerical-convention changes.

Code rollback is safe only when its reader can still interpret any new data; otherwise suspend the affected mutation path and roll forward. Do not re-enable wrong calculations, reset the repo or restore production data casually. For this package alone, authorized rollback removes only new P02 docs/tests while retaining written evidence and untouched originals.
